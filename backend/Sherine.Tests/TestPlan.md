# Test Plan for Sherine Travels Vehicle Rental Management System

## 1. Authentication

- [ ] Successful login for each user role (Manager, Owner, Driver, Client).
- [ ] Failed login with incorrect credentials.
- [ ] User registration for new clients.
- [ ] Logout functionality.

## 2. Manager Role

- [ ] View the manager dashboard.
- [ ] Add a new vehicle.
- [ ] View and manage bookings.
- [ ] View and manage drivers.
- [ ] Update account settings.

## 3. Owner Role

- [ ] View the owner dashboard.
- [ ] View financial reports.
- [ ] Download financial reports.
- [ ] Access manager features (fleet and driver management).

## 4. Driver Role

- [ ] View the driver dashboard.
- [ ] View assigned rides and their details.
- [ ] View vehicle alerts.

## 5. Client Role

- [ ] View the client dashboard.
- [ ] Book a vehicle with and without a driver.
- [ ] View booking history.
- [ ] Make a payment for a booking.
- [ ] View available vehicles.
- [ ] Use the chat feature.
- [ ] Update account settings.
